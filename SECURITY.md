# Security Policy

## Supported versions

Only the latest published release receives security fixes. If you run an older version, upgrade before reporting an issue.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately instead: go to the repository's **Security** tab and click **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could do with it.

We will acknowledge your report, keep you posted while we work on a fix, and credit you in the release notes if you wish.
